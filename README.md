# Spavik Python SDK

Spavik brings classification, regression and time-series forecasting to your
applications through an API.

The SDK is currently being prepared on **dev**. This branch is reserved for
reviewed changes promoted through a pull request; no package has been released yet.

- [Explore the SDK, examples and development setup](https://github.com/spavik-co/spavik-python-sdk/tree/dev)
- [Spavik](https://spavik.co)
- [Documentation](https://test-docs.spavik.co)
